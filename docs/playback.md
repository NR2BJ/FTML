# 데스크톱 재생 흐름

## 자동 선택

화질 메뉴의 **자동**은 다음 순서로 재생한다. 기존에 직접 선택한 화질은 자동으로 바꾸지 않는다.

1. 브라우저가 파일의 컨테이너와 영상/음성을 지원하면 직접 재생한다.
2. 영상 코덱만 지원하면 영상은 유지하고 컨테이너를 바꾸거나 음성을 AAC로 변환한다. 다른 음성 트랙을 선택한 경우에도 이 경로를 사용한다.
3. 영상 변환이 필요하면 브라우저와 서버가 함께 지원하는 GPU 코덱을 AV1, HEVC, H.264 순서로 고른다.
4. GPU 디코딩 실패 후에는 CPU 디코딩과 GPU 인코딩을 조합한 새 작업을 시도한다. 브라우저 디코더 실패는 같은 출력 코덱/해상도를 반복하지 않는다.
5. 마지막 대안은 CPU H.264이다. 자동 모드에서만 처리 지연이 계속되면 낮은 해상도를 순서대로 시도한다. 수동 선택한 화질을 조용히 낮추지는 않는다.

브라우저 이름을 고정 조건으로 쓰지 않는다. MSE 지원 여부와 MediaCapabilities의 해상도/프레임/프로필별 응답을 확인하고, 실제 재생 중 오류와 지속적인 프레임 누락을 함께 감시한다. 지원 응답만으로 모든 원본의 재생 성공을 보장하지 않는다. CPU AV1은 실시간 변환의 기본 대안으로 선택하지 않는다.

## 시간과 작업 수명

- 영상과 음성에서 각각 첫 시각을 빼지 않는다. 파일 기준 시각을 함께 보존한 뒤 같은 상수로 HLS의 상대 시각을 만든다.
- 영상 복사 탐색은 직전 키프레임과 음성을 함께 보존한다. `X-Media-Time-Origin`으로 원본 시각을 돌려주며 플레이어가 앞부분을 건너뛴다. 키프레임 탐색이 요청 시각을 지나쳤다면 정확한 변환 경로를 사용한다.
- 시작 목록은 건너뛸 앞부분을 제외해도 다음 목록 갱신까지 재생할 분량을 확보한 뒤 보낸다. 파일 끝이나 짧은 영상은 완료된 목록으로 바로 시작할 수 있다.
- 각 변환 시도는 독립된 작업 ID와 폴더를 사용한다. 실패한 조각을 지우고 같은 주소에 다시 쓰지 않는다. 새 작업에도 현재 위치, 음성 선택, 배속, 일시정지 의도를 보존한다.
- 완성된 조각만 공개한다. 종료된 작업은 다시 시작하지 않고, 프로세스가 끝난 뒤 임시 파일을 정리한다. 서버 종료 시 변환과 정리 타이머도 종료한다.
- 약 90초 이상 앞서 준비하면 변환을 멈추고 45초 미만에서 재개한다. 진행 알림 간격/조각 길이만큼 초과할 수 있다. 이 대기는 GPU 메모리 반환을 의미하지 않는다.
- 브라우저의 지나간 버퍼는 60초만 유지한다. 이미 버린 위치로 이동하면 새 작업으로 탐색한다.

## 배포 후 확인

백엔드와 프론트엔드를 함께 다시 빌드하고 재생 화면을 새로고침한다. 화질을 **자동**으로 선택하고 `I` 키로 통계를 확인한다.

1. HEVC Main 10 원본을 몇 분 재생한 뒤 앞뒤로 탐색한다. 영상 유지 여부, 배속/진행률, 프레임 누락과 자막 시각을 확인한다.
2. 음성 트랙과 배속을 바꾸고, 일시정지 상태에서도 음성을 바꾼 뒤 재개한다. 원래 위치와 정지 상태가 유지되어야 한다.
3. A380 서버에서 영상 변환을 10분 이상 시험한다. 통계의 실제 인코더, 서버 상태와 준비 분량을 확인한다. 실패하면 다른 작업/방식으로 이어지는지, 계속 실패하면 해당 시각의 서버 로그를 함께 확인한다.

로컬 자동 시험은 CPU FFmpeg의 시간축, 신호음 위치, 권한/작업 수명, 선택 및 복구 규칙을 검사한다. 실제 Firefox/Chromium 재생과 변환 강제 종료도 별도 검증했다. A380/VAAPI 드라이버의 실기 성공이나 모든 운영체제 조합을 이 시험으로 대신할 수는 없다. HDR 톤 매핑, 특수 프로필, 손상/암호화 파일과 모바일/네이티브 HLS의 완전한 호환성은 별도 검증 범위다.
