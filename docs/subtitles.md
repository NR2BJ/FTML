# 자막 처리와 배포 확인

## 처리 원칙

- 원본 미디어와 외부 자막을 수정하지 않는다. 생성·번역·업로드 결과는 기존 `/data/subtitles`에 저장한다.
- 외부 파일·업로드 파일·내장 자막은 같은 읽기/변환 계층을 사용한다. 파일명 확장자와 실제 변환기의 입력 형식을 연결하고 경로 이탈·크기 초과를 거부한다.
- SRT, WebVTT, ASS/SSA, SAMI(SMI)를 지원한다. UTF-8과 BOM이 있는 UTF-16을 읽는다. 그 외 문자 인코딩은 추측하지 않으므로 UTF-8로 변환해서 업로드한다.
- 내장 ASS는 ASS로 추출하고 다른 텍스트 자막은 WebVTT로 추출한다. PGS/VobSub 같은 그림 자막의 OCR은 추가하지 않았다. `.sub`는 텍스트/그림 종류가 모호하고 기준 프레임률이 필요할 수 있어 자동 목록에서 제외한다.

## 작업 실행과 이력

탐색기에서 영상 한 개 또는 여러 개를 선택한 뒤 영상에 **우클릭하면 자막 패널이 바로 열린다**. 상단 자막 버튼과 중간 메뉴는 없다. 아이콘·상세 보기 모두 한 번 클릭은 단일 선택, Ctrl/Cmd+클릭은 추가·해제, Shift+클릭은 표시 순서에 따른 범위 선택이다. Ctrl/Cmd+Shift는 기존 선택에 범위를 추가한다. 체크박스도 직접 누를 수 있다. 영상 재생과 폴더 열기는 더블클릭 또는 해당 항목에 초점을 둔 뒤 Enter로 한다. 선택한 영상에 우클릭하면 여러 영상을 함께 처리하고, 선택 밖의 영상에 우클릭하면 그 영상만 처리한다. Shift+F10으로도 같은 패널을 열 수 있다. 폴더·일반 파일은 자막 작업에서 제외한다.

재생기와 일괄 선택도 같은 **자막 작업** 창을 사용한다. 오른쪽 **자막 삭제** 탭에서 영상별 목록을 보고 앱에 저장한 자막만 삭제한다. 관리자는 확인 후 삭제, 일반 사용자는 삭제 요청, 열람 전용 사용자는 목록 조회만 가능하다. 내장/외부 원본 자막과 미디어 파일은 변경하지 않는다. 작업 중에도 탭을 옮길 수 있고 진행 상황·완료 결과를 다시 볼 수 있다. 자막 추출, 자막 번역, 추출 후 번역 중 선택하고 같은 Whisper 연결·음성 언어·Gemini 번역 지침을 사용한다. 저장한 번역 지침도 모든 진입점에서 사용할 수 있다. 한 번에 영상 200개까지 등록하며 일부 파일이 없거나 원본 자막이 없으면 해당 영상의 제외 이유를 따로 표시한다.

자동 원본 선택은 Whisper 추출본 → 업로드본 등 생성 폴더의 비번역 자막 → 내장 텍스트 자막 → 외부 자막 순서다. 기존 번역 결과는 자동 원본에서 제외하되, 단일 영상에서는 원하는 번역본을 명시적으로 선택해 다시 번역할 수 있다. 언어별 원본을 자동 추측하거나 ASS 안에서 번역할 언어만 구분하는 기능은 추가하지 않는다.

추출 후 번역은 두 작업을 연결한다. 추출 완료와 번역 등록을 DB에 함께 저장하므로 그 사이의 서버 재시작으로 후속 작업이 유실되지 않는다. 진행 창은 번역 종료까지 기다리며 번역만 실패하면 추출을 반복하지 않고 번역만 재시도한다. 추출과 번역은 별도 대기열을 유지하여 GPU 추출과 Gemini 요청이 서로를 막지 않는다. 동일 영상·종류·설정으로 진행 중인 중복 요청은 기존 작업 번호를 돌려주며, 완료 후 다시 실행하는 것은 허용한다.

상단의 **자막 작업**에서 영상별 검색·상태 필터·페이지 이동을 사용할 수 있다. 영상을 펼치면 실패·취소·재시도를 포함한 상세 작업 기록, 저장된 설정, 현재 결과 자막을 확인하고 재생·다운로드·새 작업을 실행할 수 있다. 재시도는 기존 행을 초기화하지 않고 새 작업 번호를 발급한다. 기존 HTTP 재시도 API를 직접 사용하는 도구는 응답의 `job_id`를 따라야 한다.

기존 DB에 남아 있는 오래된 작업도 표시한다. 과거 작업에는 단계 연결 정보가 없을 수 있으며 추정해서 연결하지 않는다. 이미 삭제된 DB 기록은 자막 저장 폴더의 해시만으로 복구하지 않는다. 목록은 이 서비스에 저장된 작업 전체이며, 작업자별 목록은 아니다. **작업 이력 보존과 결과 파일의 버전 보관은 별개**다. 재작업으로 같은 결과 파일을 교체할 수 있고, 상세 화면의 자막은 현재 존재하는 파일을 가리킨다. 자동으로 과거 작업을 재실행하거나 유료 번역을 시작하지 않는다.

등록은 `POST /api/subtitle/tasks`, 영상 목록은 `GET /api/jobs/videos`, 상세 이력은 `GET /api/jobs/history`, 등록된 작업 묶음의 상태 확인은 `GET /api/jobs/tracked`로 통일한다. 기존 단일/일괄 등록 주소는 호환 어댑터로 유지하고 내부 검증·원본 선택·등록 처리는 공유한다. 상태 확인은 작업마다 별도 요청을 보내지 않고 한 묶음으로 조회한다.

목록 이름은 `Whisper 추출 (일본어)`, `Qwen 추출 (일본어 · 1.7B · 트랙 1)`처럼 추출기를 구분한다. 번역은 `Gemini 번역 (한국어) ← 외부 자막 원본.cht.ass`처럼 실제 원본을 표시한다. 내장 자막은 이름과 트랙 번호, 추출본은 해당 추출기의 이름을 사용한다. 파일명·자막 ID는 그대로이며 기존 번역도 원본 식별 해시 또는 완료 이력이 남아 있으면 출처를 복원한다. 새 번역 작업은 등록 시 확인한 원본 이름도 저장한다. 근거가 없는 오래된 번역은 `원본 정보 없음`으로 표시하며 Whisper나 Qwen으로 추측하지 않는다. 이름 갱신 때문에 재추출·재번역할 필요는 없다.

## 추출

기본 모델은 `OpenVINO/whisper-large-v3-int8-ov`를 유지한다. Turbo는 속도를 위한 축소 모델이며 이 서비스의 일본어·한국어 정확도가 더 좋다는 실측 근거가 없어 자동 교체하지 않는다. 추출 모델 선택은 이 Whisper와 Qwen3-ASR 1.7B만 제공한다.

OpenVINO GenAI를 `2026.4.1.0`으로 고정하고 Whisper 자체의 `word_timestamps`를 모델 준비와 추론 양쪽에서 사용한다. Whisper에는 별도 강제 정렬이나 음원 분리를 적용하지 않는다. 모델 준비 시 단어 시각을 지원하지 못하면 경고와 함께 문장 시각으로 준비한다. `/v1/model/info`의 `timing_mode`와 Whisper 시작 로그로 실제 적용 여부를 확인할 수 있다.

단어 원문과 시각이 맞는 부분은 유지하고, 불일치한 부분만 같은 문장 안의 이웃 시각으로 제한한다. 한 단어 오류로 전체 처리 창이 긴 문장 시각으로 돌아가지 않는다. **Whisper가 나눈 발언 경계는 다시 합치지 않는다.** 한 발언 안에서는 Whisper 300ms, Qwen 650ms 이상의 간격과 문장 끝을 분리 기준으로 사용한다. 6초/56자 길이 목표를 넘더라도 공백·쉼 경계를 우선하며, 경계가 전혀 없는 매우 긴 결과만 12초/112자에서 제한한다. 이 규칙은 화자 식별이 아니며 원래 겹친 화자·슬래시를 제거하지 않는다. 유효한 단어 시각이 전혀 없는 문장은 문장 시각으로 돌아간다. 완전한 디지털 무음은 생략하거나 가장자리를 자르지만 작은 소리는 크기만으로 삭제하지 않는다. 배경음·음악 속 목소리의 시작과 끝은 여전히 모델의 추정이므로 실제 발화 구간과 정확히 일치한다는 보장은 없다.

빈 구간 재인식은 기본적으로 끈다(`WHISPER_GAP_RETRY_SECONDS=0`). 배경음만 있는 끝부분을 반복 인식해 헛문장을 추가할 위험을 줄이기 위한 변경이다. 명시적으로 다시 켜더라도 기존 대사 위에 겹치는 다른 문장을 추가하지 않는다. 겹쳐 읽은 처리 창에서는 경계별 소유권을 나누되 한쪽에서만 잡힌 대사는 보존한다. 실제 대사일 수도 있는 감사/인사 문구를 금지어로 삭제하지 않는다. 이미 저장한 잘못된 자막은 자동 수정되지 않으므로 다시 추출해야 한다.

음성 추출의 고정 채널 혼합·강한 음량 정규화·압축을 제거했다. 선택한 음성을 표준 모노/16kHz로 바꾸고 `aresample=16000:async=1:first_pts=0`으로 시작 지연과 타임스탬프 공백을 보존한다. 재생기에서 생성하면 현재 선택한 음성 트랙을 사용한다. 두 번째 이후 음성의 결과는 `whisper_<언어>_track<N>.vtt`로 구분하며 일괄 생성은 첫 음성을 사용한다.

생성이 너무 느리거나 A380 메모리가 부족하면 Portainer 환경 변수 `WHISPER_WORD_TIMESTAMPS=false`로 문장 시각 방식으로 돌아갈 수 있다. 기존 캐시 모델을 지우거나 GPU 드라이버를 바꿀 필요는 없다. 단어 시각은 추론 비용이 추가되며 A380의 실제 메모리 사용은 배포 후 확인해야 한다.

### Qwen3 비교

**자막 작업 → 추출 모델 → Qwen3-ASR 1.7B INT8 (비교용)**을 선택한다. 기본값은 Whisper large-v3 INT8이며 Qwen ASR 0.6B 선택은 제거했다. 기존 0.6B 결과는 계속 읽을 수 있지만 새 작업/재시도는 1.7B로 다시 등록한다. 설정의 임의 Whisper 모델 선택 목록과 클라우드 음성 인식은 제거했다. 일본어·한국어·영어 영상은 실제 음성 언어를 직접 선택해 비교하는 편이 좋다.

공식 Qwen 원본을 첫 실행 때 내려받아 OpenVINO INT8로 변환한다. 모델 원본과 변환 결과는 기존 `whisper_models` 볼륨의 `/models` 아래에 저장하며 Whisper 캐시를 지우지 않는다. 다운로드/변환은 오래 걸릴 수 있고 추가 디스크·호스트 RAM을 사용한다. 로컬 1.7B 시험 캐시는 정렬 모델 포함 약 8GB였으며, 변환 중 임시 파일과 Docker 이미지 공간도 별도로 필요하다. 모델을 모두 바꿔가며 내려받기 전에 디스크 여유를 확인한다. 변환 도중 실패한 폴더는 정상 모델로 재사용하지 않는다.

변환기의 내부 임시 모델은 `/models/ftml-openvino/export-*/tmp` 아래에 만들고, 완성한 모델만 캐시로 옮긴다. 변환 성공·실패·취소·시간 초과 시 해당 작업 폴더를 정리한다. 변환 프로세스에만 `TMPDIR`/`TMP`/`TEMP`를 지정하므로 서버 전체의 음성 업로드 임시 경로는 바뀌지 않는다. 강제 컨테이너 종료까지 정리가 보장되는 것은 아니며, 다른 작업·모델의 파일을 자동 삭제하지 않는다.

`No space left on device`/디스크 할당량 초과는 GPU 메모리 부족과 다르다. 변환 로그의 해당 오류나 직접 발생한 저장 공간 오류는 HTTP 507과 한국어 안내로 전달하며 자동 반복 재시도하지 않는다. 변환 직전의 여유 용량도 로그에 남긴다. `/tmp`와 `/models`가 같은 호스트 디스크를 쓰면 임시 경로 변경만으로 여유 용량이 늘지 않는다. `whisper` 컨테이너의 `df -h /tmp /models`, `df -i /tmp /models`와 호스트의 `docker system df`로 용량·inode·빌드 캐시를 확인한다. 최종 캐시 크기는 변환 도중 최대 사용량이 아니다. 공간 확보 시 DB/모델 볼륨을 일괄 삭제하거나 `docker system prune --volumes`를 실행하지 않는다.

인식은 `WHISPER_DEVICE`(기본 GPU), 시간 정렬은 공식 `Qwen3-ForcedAligner-0.6B`의 CPU 구현을 사용한다. OpenVINO 자체 정렬 경로의 일본어/한국어 분절 제한을 피하기 위한 구성이다. `QWEN_ALIGNER_THREADS` 기본값은 4다. 인식 모델은 한 번에 하나만 보유하고 모델 교체와 추론을 같은 잠금 안에서 수행한다. 작업 등록 때 모델과 작품 용어를 고정하므로 다른 작업이 모델을 바꾸거나 사전을 편집해도 이미 등록한 작업 설정은 유지한다.

Qwen은 30초 창에 겹침을 두어 처리하고 단어 시각을 전체 영상 시각으로 환산한다. 시작·끝이 같거나 한중일 글자 여러 개가 극히 짧은 시각에 몰린 문장은 바로 합치기 전에 **인식 원문을 그대로 두고 시간만 재정렬**한다. 빠르게 발음된 일반 영단어는 글자 수만으로 이상 시각으로 분류하지 않는다. 기존 CPU 정렬기를 재사용하며 새 모델을 추가하지 않는다. 이웃 문장 사이의 시간 경계로 제한한 최대 12초 음성에 같은 문장을 넣고, 원문·시각 순서가 유효하고 불확실한 시각이 해소된 결과만 채택한다. 정상 이웃 단어가 600ms보다 크게 움직이면 거절한다. 원래 30초 입력 창당 최대 두 번이며, 실패한 창을 나누는 재처리에서도 이 예산을 공유한다. 따라서 CPU 처리 시간은 늘 수 있고 A380 서버에서 실제 증가량을 확인해야 한다. 시도/채택 수는 작업 안내에 표시한다.

재정렬을 채택하지 못하면 기존 시각으로 돌아간다. 여전히 시작·끝 시각이 같은 단어는 가까운 단어에 합치고, 고립된 경우 고정한 정렬 모델의 80ms 시각 해상도 한 칸으로만 추정한다. 이 수는 **작업 이력의 확인 안내**에 남긴다. 멀리 떨어진 다음 대사까지 표시 시간을 늘리지 않는다. 시각이 모두 없거나 원문/정렬 결과가 일치하지 않으면 긴 자막을 만들어 성공으로 처리하지 않고 실패를 알린다. 강제 정렬도 잘못 인식한 문장을 사실로 만들어 주지 않으며 노래·빠른 대사의 정확도는 재생 확인이 필요하다.

Qwen의 순간적인 깜빡임을 줄이기 위해 이어붙인 최종 자막 중 650ms 미만의 표시는 최대 550ms만 뒤로 연장한다. 시작 시각을 당기지 않고 다음 대사 40ms 전·영상 끝에서 제한하며, 겹친 화자의 시각은 그대로 둔다. 완전한 디지털 무음의 끝점 정리는 이 보정보다 우선한다. 이는 발화 시각을 새로 알아내는 정렬이 아니라 제한적인 가독성 보정이다. 모델이 긴 무음을 단어 안에 포함했거나 가사를 틀리게 인식한 경우는 남을 수 있다. Whisper에는 이 표시 연장을 적용하지 않는다. 새로운 묶음/시각 정책은 다시 추출한 결과에만 반영하며, 번역도 새 원본을 기준으로 다시 해야 한다. 기존 저장 자막을 자동으로 덮어쓰지 않는다.

Qwen의 쉼 기준을 늘리더라도 쉼표·쌍점 등으로 끝나는 400ms 이상 발언 뒤 300ms 이상 쉬면 별도 자막으로 유지한다. 호명 뒤 다른 사람의 질문까지 묶는 경우를 줄이기 위한 보조 기준이며, 짧은 감탄사 조각은 다음 문장과 이어질 수 있다. 실제 화자를 판별하는 기능은 아니다.

일본어 정렬기가 전각 숫자·반각 가나 등을 정규화하더라도 같은 내용이면 오류로 처리하지 않는다. 원문의 글자 경계를 대응시켜 자막에는 기존 표기·따옴표·문장 부호를 보존한다. 실제 글자가 빠지거나 다른 경우, 시각이 역전되거나 크게 벗어난 경우는 여전히 거절한다. 구간 끝에서 모델의 시각 격자 한 칸만큼 넘친 단어는 음성 끝으로 제한하되, 긴 무음을 메워 붙이지 않는다.

정렬 검사에 실패한 구간만 경계 앞뒤 1초를 겹쳐 더 짧게 재인식한다. 최대 두 단계로 제한하므로 일반적인 30초 창은 16초, 다시 실패한 쪽만 약 9초로 나뉜다. 이미 성공한 앞부분을 다시 처리하지 않으며 GPU/저장 공간 등 다른 오류는 이 재처리 대상이 아니다. 복구한 구간 수는 작업 이력에 표시한다. 끝까지 복구하지 못하면 실패한 영상 시각과 이유를 HTTP 422와 서버 로그에 남기고 기존 자막을 보존한다. 빈 결과를 성공으로 위장하거나 실패 구간을 조용히 누락하지 않는다. 실패한 전체 작업의 중간 결과를 디스크에 저장하여 이어가는 기능은 아직 없다.

결과는 `qwen3_<언어>_1_7b_track<N>.vtt`로 저장해 Whisper 결과와 구분한다. 재생기에서 두 결과를 바꿔가며 누락, 무음, 인사 환각, 고유명사, OP/ED를 비교한다. 같은 Qwen 설정으로 재작업하면 기존 파일의 버전을 보관한 뒤 교체한다. 1.7B가 A380 6GB에서 항상 충분한 여유로 동작하거나 Whisper보다 좋다는 보장은 없다. 첫 시험은 영상 변환을 동시에 돌리지 말고 한 영상에서 시작한다. 메모리가 부족하면 기존 Whisper를 사용한다. 과거 0.6B 캐시와 결과는 자동 삭제하지 않는다.

Whisper는 기본적으로 `WHISPER_SPEECH_BOUNDARIES=true`를 사용해 유효한 단어 시각에 포함된 긴 선행 무음만 보수적으로 줄인다. 문장 시각과 조금 겹쳐 어긋난 단어도 단어 시각으로 취급하여 보정 대상에서 빠지지 않게 하되, 원래 문장 경계 밖으로 표시 시작을 앞당기지는 않는다. 문장 첫 짧은 조각에 이전 발화의 검출 여유가 걸려 있어도 이후의 긴 쉼과 말소리 시작을 확인할 수 있으면 보정한다. 첫 두 조각에 무음이 나뉘어 붙은 경우에는 실제 검출된 쉼과 끝부분의 말소리가 함께 확인될 때만 두 조각을 한 표시 단위로 합쳐 늦춘다. 글자별 시각을 균등하게 만들어 내지 않는다.

음성은 자르지 않고 문구와 표시 묶음의 끝 시각은 보존하며, 말소리 검출 밖의 대사/노래를 삭제하지 않는다. 단어 시각 없는 문장이나 검출이 불확실한 구간에는 적용하지 않는다. 검출 실패 시 원래 시각을 유지하고 결과에 상태를 표시한다. 단일 단어 보정과 앞부분 묶음 보정 수를 작업 이력에서 구분하며 문제 시 환경 변수로 끌 수 있다. 결과 진단의 `timing_policy_version: 2`로 새 추출 여부도 확인할 수 있다. 이는 강제 정렬이 아니므로 배경음·겹친 대사·모델의 잘못된 단어 시각이 모두 해결되지는 않는다. Qwen에는 이 보정을 적용하지 않는다.

겹쳐 추출한 창은 문장으로 묶기 전에 단어를 비교한다. 시간과 내용이 일치하는 경계 단어를 찾으면 그 뒤를 연결하고, 짧은 단어의 중복도 제외한다. 같은 추론 안의 반복 응답/겹친 화자는 유지한다. 모델 시각은 실제 입력 음성 창 끝에서 제한한다. Qwen의 시각 길이 0인 단어는 시각에 여유가 있으면 문장 끝을 넘겨 붙이지 않으며 최대 80ms 범위에서 별도로 표시한다. 분리할 여유가 전혀 없으면 기존 병합을 유지하고 불확실한 단어 수에 포함한다. 모델 자체가 다른 발언에 잘못 정렬한 단어까지 정확히 복원하는 기능은 아니다.

**Silero 말소리 검출 비교**는 별도의 선택적 통계 기능이다. 원음을 자르거나 무음으로 덮지 않고, 인식 결과 중 말소리 검출과 겹치지 않은 자막 수만 기록한다. 노래·속삭임을 놓칠 수 있으므로 검출 밖이라는 이유만으로 삭제하지 않는다. 통계는 겹쳐 읽은 음성 구간을 중복 계산하지 않으며 작업 완료 안내/상세 이력에 표시한다.

개발용 16GB Mac에서는 실제 ASR/정렬 모델을 올리지 않는다. 저장된 원시 결과와 가짜 모델 시험을 사용하고 검사·빌드는 하나씩 실행한다. 실제 추론 비교는 메모리 여유를 확인한 Debian A380 환경에서 별도로 한다.

운영 결과를 덮지 않는 비교 도구는 `whisper/benchmark.py`다. 16kHz PCM16 WAV를 지정하고 `--model`, `--language`, `--output`, 선택적 `--observe-speech`를 사용한다. 출력 폴더에 VTT와 진단 JSON을 저장한다. Mac CPU의 실행 시간은 Debian A380의 처리 속도 지표가 아니다.

### 작품 용어

불안정한 작품/노래 자동 검색과 가사 수동 입력·재정렬은 제거했다. 검색은 Gemini 웹 검색이 아니라 Wikipedia의 첫 결과에 의존해 명확한 작품명도 다른 문서로 연결될 수 있었기 때문이다. 가사 자동 수집도 하지 않는다. 단일 영상의 **작품 용어 사전 (선택)**에서 관리자가 기존 이름·읽기·한국어 표기를 확인하거나 수정할 수 있다. 작성은 필수가 아니며 저장된 사전과 과거 결과는 보존한다.

사전은 영상 폴더별로 저장하고 하위 폴더는 가장 가까운 저장 사전을 따른다. 루트 영상은 파일별로 분리한다. 추출·번역 등록 시점에 사전을 고정하므로 뒤늦은 수정이 진행 중 작업에 섞이지 않는다. 원어/읽기는 추출 힌트, 한국어 표기는 Gemini 번역 참고로 사용한다. 과거 가사 보정 작업의 재시도는 안내와 함께 거절하므로 일반 추출로 다시 등록한다.

## 번역

새 번역은 Gemini만 지원한다. 예전 번역 파일은 보존한다. 음성 인식은 로컬 전용이며 OpenAI 음성 인식 키와 과거 Whisper 모델 선택 설정은 삭제한다. 과거 클라우드 연결은 이력 참조용으로만 비활성 상태로 남긴다.

ASS를 일반 VTT로 먼저 납작하게 만들지 않는다. 자막 번호·시작/끝·스타일·선행 효과 명령을 프로그램이 보관하고 Gemini에는 문장만 보낸다. 응답 번호·문장 수·빈 문장을 검증한 다음 ASS로 다시 조립한다. 위치·회전·이동·문장 전체의 페이드 같은 효과는 유지된다. 출력 이름에 원본 식별 해시를 넣어 다른 원본의 번역이나 기존 결과와 구분한다.

번역 후 글자 수/어순이 달라지는 노래 효과, 문장 중간의 복잡한 효과는 원문을 억지로 재배치하지 않는다. 원문 효과를 보존하고 별도 일반 번역문을 추가한다. 완료 결과의 `plain_effect_fallbacks`와 재생기 번역 창에서 해당 개수를 확인할 수 있다. 원문 주석 없이 글자별 효과만 남은 자막은 완전한 문장 복원이 불가능할 수 있다. 화면의 간판에 정확히 들어맞는 글자 폭·줄바꿈까지 자동 보장하지 않는다.

기존에 VTT로 저장한 번역에는 위치·효과가 없으므로 원본 ASS를 선택해 다시 번역해야 한다. 자동으로 유료 번역을 실행하거나 기존 파일을 삭제하지 않는다.

## 표시

주 자막의 ASS/SSA는 libass-wasm 4.1.0으로 그린다. 실행 파일·WASM·저작권 고지를 프론트엔드에 함께 배포하며 외부 CDN은 사용하지 않는다. MKV의 첨부 TTF/OTF/TTC/WOFF2 글꼴을 읽고, 없는 글꼴과 한중일 문자는 백엔드의 Noto CJK를 대체 글꼴로 사용한다. 정확한 원본 서체가 없으면 글자 모양·폭이 달라질 수 있다. 별도 폴더의 모든 글꼴을 임의로 탐색하거나 공개하지 않는다.

자막 설정의 **일반 자막으로 보기**를 켜면 위치·애니메이션을 제거하고 기존 하단 표시로 바뀐다. 원형 표시가 실패해도 일반 표시로 전환하며 알림을 띄운다. 글꼴 크기·색·배경 설정은 일반 표시에 적용한다. 보조 자막은 겹치는 두 ASS 화면을 피하기 위해 일반 표시를 사용한다.

두 표시 방식은 실제 영상 시각에 HLS 원점을 더해 사용한다. 전체화면·화면 크기 변경에서는 영상의 실제 영역과 검은 여백을 구분한다. 소스 교체 중에는 이전 자막을 감추고, 탐색·배속·동기화 보정도 같은 시간 기준으로 처리한다.

생성·번역 창을 닫아도 재생기가 작업 완료를 감지해 목록을 갱신한다. 실행 중 작업의 확인 주기는 3초이며 네트워크 지연은 추가될 수 있다. 같은 이름으로 다시 생성된 자막은 내용도 다시 읽되 현재 선택은 바꾸지 않는다. 목록 요청 실패는 재시도하고, 다른 영상으로 넘어간 뒤 도착한 이전 응답은 적용하지 않는다.

ASS를 바꾸거나 다시 읽을 때는 이전 그리기 영역을 폐기한다. 재생·정지·탐색·배속 상태를 렌더러에 전달하며 재생 중 렌더링은 30fps로 제한한다. 다운로드는 자막 옆 버튼을 **클릭**한 뒤 ASS·SRT·VTT를 선택한다. 해당 형식이 원본이면 **(원본)**으로 표시한다.

## PiP 자막

HTTPS에서 재생기 안의 **PiP 버튼 또는 P 키**를 사용한다. 브라우저가 Document PiP를 제공하면 영상·ASS 효과·일반/보조 자막·조작 버튼을 함께 새 창으로 옮긴다. 같은 영상 요소와 HLS 연결을 유지하므로 PiP를 위해 서버에서 다시 인코딩하지 않는다. 창을 닫거나 돌아오기 버튼을 누르면 원래 자리로 복귀하고, 다른 영상으로 이동하면 PiP도 닫는다.

ASS는 PiP 창에서 렌더러를 실행해 원래 탭의 화면 갱신이 중단되어도 계속 그린다. 일반 자막의 글꼴 설정은 유지하되 작은 창에 맞춰 크기를 줄인다. 탐색·배속·시간 보정은 본 화면과 같은 기준을 사용한다.

Document PiP가 없으면 기존 영상 전용 PiP를 사용한다. 이 경우 선택한 자막을 표준 TextTrack으로 전달하지만 실제 표시 여부는 브라우저에 달려 있고 ASS 효과는 보존되지 않는다. 브라우저 자체의 영상 위 PiP 아이콘이나 메뉴로 열어도 이 제한이 적용될 수 있으므로 효과까지 보려면 **서비스 재생기 안의 버튼**을 사용한다. 브라우저 이름으로 지원을 단정하지 않고 실행 시 기능 제공 여부를 확인한다.

참고: [Chrome Document PiP 안내](https://developer.chrome.com/docs/web-platform/document-picture-in-picture), [Firefox 기본 PiP 자막 안내](https://support.mozilla.org/en-US/kb/about-picture-picture-firefox).

## 재배포와 확인

**현재 배포는 [GHCR·Portainer 편집기 안내](ghcr-portainer.md)를 따른다.** backend, frontend, whisper의 게시가 모두 성공한 같은 커밋 태그로 업데이트한다. 서버에서 재빌드할 필요는 없다. 기존 볼륨/UID/GID/렌더 장치 그룹은 유지한다. 첫 Qwen 선택 때 추가 모델 준비가 시작된다. 기존 스택에 `WHISPER_GAP_RETRY_SECONDS`가 별도로 설정되어 있다면 `0`으로 바꿔야 새 기본 정책이 적용된다. 진행 중인 추출/번역은 먼저 끝낸다. 아래 이전 변경 범위는 참고용이며 이번에는 세 이미지를 함께 갱신한다. Git에서 분리된 스택의 읽기 전용 마운트는 편집기에서 별도로 반영한다.

배포 후 일본어 영상 한 개를 Qwen1.7B로 추출해 Whisper 결과와 비교한다. 먼저 대사 구간과 무음/OP/ED를 확인하고, 필요하면 저장된 용어 사전의 효과를 별도로 비교한다. 첫 시험부터 일괄 작업과 영상 변환을 동시에 실행하지 않는다. Docker 이미지 빌드, A380 실측, 실제 Gemini 번역은 개발 Mac의 회귀 시험과 별도로 확인해야 한다.

로컬 Compose 관리 환경에서는 저장소 폴더에서 다음 명령을 사용할 수 있다. Portainer 관리 스택 옆에 별도 Compose 스택을 새로 만들라는 뜻은 아니다.

```sh
git pull --ff-only origin main
docker compose pull backend frontend whisper
docker compose up -d --no-build
```

1. 브라우저를 새로고침하고 원본 ASS를 선택한다. 위치·색상·노래 효과가 나오는지 확인한다.
2. 자막 설정에서 일반 표시를 켰다 끄고, 탐색·배속·전체화면·음성 변경을 시험한다.
3. 짧은 영상에서 생성한다. 알려진 언어를 직접 선택하고 실제 음성 트랙도 확인한다. Whisper 로그의 `timing mode: word` 여부와 무음 전후 시각을 본다.
4. 같은 원본 ASS를 Gemini로 번역하고 새 ASS 결과를 선택한다. 복잡한 효과 구간의 별도 번역문 안내와 원본 보존을 확인한다.
5. 기존 SRT/VTT와 업로드 ASS를 열고 다운로드 형식 세 가지를 확인한다.

## 검증 범위

Go/Python 회귀 시험, 실제 FFmpeg 입출력, Chromium/Firefox의 실제 WASM 표시를 시험한다. Gemini 응답 시험은 가짜 응답을 사용하므로 번역 품질 검증이 아니다. Mac CPU의 작은 Whisper로 단어 시각 API를 실행한 결과를 A380/large-v3의 성능·정확도 증명으로 취급하지 않는다.

참고: [OpenVINO Whisper 시간 설정](https://docs.openvino.ai/2026/api/genai_api/_autosummary/openvino_genai.WhisperGenerationConfig.html), [Turbo 모델 설명](https://huggingface.co/OpenVINO/whisper-large-v3-turbo-int8-ov), [ASS 렌더러 소스와 라이선스](https://github.com/libass/JavascriptSubtitlesOctopus).
